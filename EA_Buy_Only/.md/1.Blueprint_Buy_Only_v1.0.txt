- **กดปุ่ม REFILL หนึ่งครั้ง เพิ่มทุนเสมือน ($):** เติมเงินจำลองเข้าพอร์ตทีละ 10.0 ดอลลาร์เมื่อกดปุ่ม

- **ขึ้นบันไดเพิ่ม Lot ทุกๆ ($):** ทุกๆ 50.0 ดอลลาร์ที่พอร์ตโตขึ้น
- **ขนาด Lot ที่เพิ่มขึ้นบันได:** ขยับเพิ่มทีละ 0.01 ล็อต
Lot สูงสุดที่อนุญาต (คูณ 0.01): ค่าเริ่มต้น 4 หมายถึง lot ไม่เกิน 0.04 / ค่า 0 = ไม่จำกัด

อธิบาย สูตรบันได Lot: คำนวณทุกครั้งที่ปิดจบรอบ (Basket ว่าง) โดย Lot = 0.01 × จำนวนครั้งเต็มของ 50 ที่อยู่ในทุนรวม (ปัดเศษทิ้ง) และขยับได้ทั้งขึ้นและลงตามทุนจริงของตอนนั้น
เช่น ทุน 50 = 0.01 / ทุน 120 = 0.02 / ทุน 80 = 0.01 / ทุน 230 = 0.04 (ไม่ใช่ 0.03 เพราะนับจากยอดทุนรวมทุก ๆ 50 ไม่ใช่บวกทีละรอบ)
และ Lot สูงสุด เป็นเพดานกั้นไว้ เช่น ตั้ง 4 = lot ไม่เกิน 0.04 แม้ทุนรวมโตเกิน 200 ไปแล้วก็ตาม (แต่ถ้าทุนลดลง lot ลดตามสูตรเหมือนเดิม) ตัวอย่างเต็ม: ทุนเกิน 300 → สูตรให้ 0.06 แต่ถูกหั่นเหลือ 0.04 / ทุนลดเหลือ 90 → lot กลับมา 0.01 ตามสูตร

ถ้า Virtual Equity ขาดทุนถึงจำนวนทุนเริ่มต้น ติดลบ/เหลือ $0 บอท  ให้หยุดทำงาน รอกด REFILL
