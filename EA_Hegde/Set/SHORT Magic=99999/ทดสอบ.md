ได้ครับ เปลี่ยนเป็นรันบนกราฟ **Demo** ทั้งหมดได้ และทำทีละ Preset ได้ครับ แต่ต้องปรับความเข้าใจสองจุดก่อน:

1. 16 Preset ไม่ใช่ 16 กรณีที่ “โหลดแล้วกด HEDGE เหมือนกันทั้งหมด” บางตัวต้องรอ Auto บางตัวต้องรอราคา บางตัวต้องรอ Report และสองตัวสุดท้ายต้องถูกปฏิเสธตั้งแต่เริ่ม
2. ส่งผลเมื่อจบแต่ละ Preset ได้ตาม Workflow ใหม่ที่คุณเลือก แต่ Experts อย่างเดียวไม่พอสำหรับบางกรณี ต้องมีภาพ Inputs/Trade/History หรือ CSV ประกอบครับ 

ไม่ใช้ Strategy Tester แล้ว ดังนั้นกรณีตามราคาและ Report จะต้องรอเหตุการณ์จริง ไม่เร่งเวลาย้อนหลังครับ

## 1. กติกาที่ใช้ร่วมกันทุก Preset

### ก่อนโหลดตัวถัดไป

- ใช้บัญชี Demo Hedging, XAUUSD และ Source `1a3b38f`
- หนึ่ง Instance ต่อ Symbol + Magic
- ตรวจว่า Position ของ `XAUUSD + Magic 99999` จบแล้วก่อนเปลี่ยนโปรไฟล์
- ไม่เปลี่ยน Magic หรือ Point Digits ระหว่างกรณี Restart
- เก็บเวลาเริ่ม–จบและค่าที่โหลดจริง
- ไม่ลบ History/State เหมารวมเพื่อเริ่มใหม่ 

การเปลี่ยน Inputs แล้วกด OK จะทำให้ EA เริ่มระบบใหม่ จึงต้องบันทึกการเปลี่ยนค่า ไม่ถือว่าเป็นการรันต่อด้วย State ใน RAM เดิมครับ 

### วิธีจบรอบของ Preset ที่เปิด Auto

Preset 02–10 และ 13 เปิด Auto Reopen อยู่ หากกด CLOSE ALL อย่างเดียว ระบบอาจเปิดคู่ใหม่อีกเมื่อผ่าน Gates

ให้จบรอบแบบนี้:

1. เก็บหลักฐานช่วงทดสอบก่อน
2. เปิด Inputs เปลี่ยนเฉพาะ `InpReopenOnEmpty=false` แล้วกด OK
3. บันทึกว่าเข้าสู่ช่วง “จบรอบ” ซึ่งเกิด Reinitialization แล้ว
4. ใช้ CLOSE ALL สำหรับ Position ใน Scope นี้ และตรวจว่าปิดจริงจน Basket ว่าง
5. จึงโหลด Preset ถัดไป

ผลหลังเปลี่ยนค่านี้ไม่เอามาปนเป็นหลักฐานของช่วงทดสอบเดิม และอย่าใช้การปิด Algo Trading แทน เพราะจะห้าม EA ส่งคำสั่ง Trade รวมถึงคำสั่งปิด/Modify ด้วยครับ 

## 2. Preset 01–04 — ปุ่ม, Cut Loss และ BE

### 01 — `SHORT_01_MANUAL.set`

เป้าหมาย: ตรวจปุ่มและ Strict Basket

ขั้นตอน:

1. โหลด Preset แล้วตรวจ `InpReopenOnEmpty=false`
2. กด `HEDGE OPEN (B+S)` หนึ่งครั้ง
3. เก็บภาพ Buy/Sell, Volume และ SL ทั้งสองขา
4. ขณะ Basket ยังมี Position:
 - กด HEDGE ซ้ำหนึ่งครั้ง — ต้องไม่เพิ่มคู่
 - กด BUY LOCKED และ SELL LOCKED — ต้องไม่เปิดเดี่ยว
5. ตรวจปุ่มปิดเป็นสถานการณ์แยก:
 - รอบหนึ่ง: CLOSE BUY แล้วตรวจขาที่เหลือ จากนั้น CLOSE SELL
 - รอบถัดไป: CLOSE SELL ก่อน แล้ว CLOSE BUY
 - รอบถัดไป: CLOSE ALL
6. เมื่อ Basket ว่าง กด REFILL หนึ่งครั้ง เก็บยอดก่อน/หลัง
7. ตรวจ Restart ด้วย Inputs/Identity เดิม แล้วดูว่า REFILL และ Cycle ที่มีหลักฐานคงอยู่

ถ้า Position ปิดจาก SL ก่อนกดปุ่ม ต้องแยกเหตุ ไม่อ้างว่าปุ่มเป็นผู้ปิด ส่วน Restore Trailing Best จะพิสูจน์ได้เมื่อมี Best ที่เกิดหลัง Arm จริง ไม่ใช่จาก REFILL/Restart อย่างเดียวครับ 

ส่ง: Experts + ภาพ Inputs/Trade/History + REFILL ก่อน/หลัง Restart

### 02 — `SHORT_02_CUT.set`

เป้าหมาย: Cut Loss โดยไม่มี BE/RR/Trailing แย่งปิด

ขั้นตอน:

1. โหลด Preset แล้วรอ Auto เปิดเอง ไม่กด HEDGE
2. หาก Spread>25 ให้รอ — ไม่เพิ่มเกณฑ์
3. เมื่อเปิดคู่แล้ว เก็บ SL และราคาเข้า
4. รอให้ขาหนึ่งปิดด้วย SL
5. ตรวจว่าระบบไม่เปิดขาที่หายกลับมา ขาที่เหลือยังอยู่ภายใต้ Protection
6. เก็บเหตุการณ์แล้วจบรอบตามวิธีหยุด Auto ด้านบน

ส่ง: Experts + ภาพ SL/Trade + History ที่แสดงเหตุ SL

### 03 — `SHORT_03_BE_FIXED.set`

เป้าหมาย: BE Fixed

ขั้นตอน:

1. รอ Auto เปิดคู่ ไม่กดปุ่มเปิดหรือปิดระหว่างตรวจ
2. รอขาที่กำไรถึง Trigger=120
3. เก็บภาพ SL เมื่อ BE ทำงาน
4. หากราคาวิ่งต่อ ให้เก็บภาพอีกครั้งเพื่อตรวจว่าล็อกตาม Trigger ไม่เลื่อนตามกำไรแบบ BE Trailing
5. ตรวจว่า SL ไม่คลายกลับเมื่อราคาย่อ แล้วจบรอบ

เป้าล็อกตามสูตรคือ 20% ของ 120 = 24 Points แต่ต้องตรวจราคา SL และผล Broker จริง ไม่สรุปจากสูตรอย่างเดียว

### 04 — `SHORT_04_BE_TRAILING.set`

เป้าหมาย: BE เลื่อน SL ตาม Step

ขั้นตอน:

1. รอ Auto เปิดคู่
2. รอถึง Trigger=120 และราคาผ่านหลาย Step
3. เก็บ SL หลายจุดพร้อมเวลา/ราคา
4. เมื่อราคาย่อ ตรวจว่า SL ไม่เลื่อนกลับในทิศที่ป้องกันแย่ลง
5. จบรอบหลังเก็บเหตุที่ต้องการได้

สำหรับ 03–04 ถ้าราคาไม่ถึงเงื่อนไขในช่วงที่คุณรัน ให้รายงานว่าเหตุไม่เกิด ไม่ต้องฝืนรอหรือสรุปว่าผ่านครับ 

## 3. Preset 05–09 — Trailing, RR และ Auto Gates

| Preset | ต้องทำอะไร | ปุ่มที่ใช้ระหว่างตรวจ |
|---|---|---|
| 05 Armed Trailing | รอ Auto เปิด → รอถึง Arm=120 → เก็บ Best/ARMED → รอ Pullback=50 และตรวจเหตุปิด | ไม่กดปิดเองก่อนเหตุที่กำลังตรวจ |
| 06 RR | รอ Auto เปิด → รอขาที่กำไรถึงเป้าจาก Trigger×200%=240 → ตรวจ Log/History เหตุ RR | ไม่กดปิดเองเพื่อแทน RR |
| 07 Auto Timeout | เก็บเวลาที่ Basket ว่าง → รออย่างน้อย 300 วินาทีและ Gates ผ่าน → ดู Auto เปิดรอบใหม่ | ไม่กด HEDGE เพื่อพิสูจน์ Auto |
| 08 Session | รอช่วง Server 01:00–04:00 → ตรวจ Block และช่วงนอกเวลา → ตรวจว่าผ่าน Gate อื่นแล้วจึงเปิดได้ | ไม่ใช้ HEDGE พิสูจน์ Session Gate |
| 09 Invalid Session First | เก็บคำเตือน Session1=`99:00` → ตรวจว่า Session2=`07:00–12:00` ยังถูกตรวจ | ไม่ต้องกดปุ่มเปิด |

รายละเอียดสำคัญ:

- 05: RR ปิดอยู่ แต่ BE ยังเปิด ถ้า BE SL ปิดก่อน Trailing ต้องบันทึกตามเหตุ ไม่ถือว่า Trailing ผ่านแล้ว
- 07: Timeout ครบแต่ Spread ยังเกิน 25 ก็ยังไม่ต้องเปิด
- 08–09: การไม่มี Order อย่างเดียวไม่พอ ต้องมีเวลา Server และสถานะ Gates ประกอบ
- หากต้องตรวจ Protection ขณะ Session Block ต้องมี Position ค้างอยู่จริงและเกิดเหตุ Protection ให้ตรวจ 

ส่ง: Experts + Inputs + ภาพ Trade/SL/History ตามเหตุ โดย 07–09 เพิ่มเวลาที่ Basket ว่างหรือเข้า–ออก Session

## 4. Preset 10–11 — Report ต้องรอเวลาจริงหรือใช้ Fixture

### 10 — `SHORT_10_REPORT_TESTER.set`

แม้ชื่อไฟล์มีคำว่า TESTER ก็ใช้ค่า Inputs บน Demo ได้ แต่ให้ระบุในหลักฐานว่า `DEMO` ไม่ใช่ Tester

ขั้นตอน:

1. โหลดไฟล์ เปิด ReportDays=1 และ Auto Reopen ตาม Preset
2. บันทึกเวลาเริ่มรอบ Report ที่ EA ใช้อยู่จริง
3. รอครบ Period หนึ่งวันนับจาก State นั้น และให้ Basket ว่าง
4. ตรวจ `CSV COMPLETE` / `Report Cycle COMPLETE` และเก็บ CSV
5. ตรวจว่าเปิดรอบใหม่หลัง Report จัดการเสร็จ

ไม่ใช่รอแค่ข้ามเที่ยงคืน และการโหลด Preset ไม่ได้เริ่ม RPD ใหม่เสมอ หาก Scope นี้มี Report State อยู่แล้วครับ 

### 11 — `SHORT_11_REPORT_DEMO.set`

เป้าหมาย: Manual Report Gate / Recovery / Failure โดยปิด Auto Reopen

- กรณีปกติ: เมื่อ Report ถึงกำหนด กด HEDGE แล้วตรวจว่ารายงานจัดการก่อนเปิดคู่
- Recovery: ต้องมี CSV ที่สมบูรณ์ของ Demo Scope นี้ และจัด RPD ตาม Fixture ที่สำรองไว้
- Failure: ต้องจัดไฟล์ปลายทางผิดรูปแบบตาม Fixture แล้วตรวจว่า HEDGE ถูก Block

อย่าแก้ RPD หรือสร้างไฟล์ทับด้วยตัวเองตอนนี้ครับ สองกรณีหลังต้องระบุชื่อ Key/ไฟล์จริงและ Snapshot ก่อน เพื่อไม่แตะรอบ Report ของชุดอื่น การกด HEDGE ธรรมดาไม่ได้พิสูจน์ Recovery หรือ Write Failure ครบครับ 

ส่ง: Experts + CSV + ค่า/ภาพ RPD ที่เกี่ยวข้อง + History

## 5. Preset 12–14 — ต้องแยกข้อมูลและมี Fixture

### 12 — `SHORT_12_CAPITAL_ZERO.set`

ตัวนี้ไม่ควรโหลดต่อจาก 01–11 แล้วคาดว่าทุนจะเป็นศูนย์ทันที เพราะ Magic 99999 จะมี Closed Net และอาจมี REFILL แล้ว

ต้องเตรียม Scope ทดสอบสะอาดที่ไม่ปนชุดเดิมก่อน ไม่ใช้ Magic 99998 ที่สงวนสำหรับ Long Run และไม่ลบ State เหมารวม

เมื่อเตรียมครบ:

1. โหลด Preset ทุนเริ่มต้น=0
2. ตรวจ Virtual Equity จริงว่าไม่เกิน 0
3. รอดู Auto ถูก Block
4. กด HEDGE หนึ่งครั้ง — ต้องถูก Capital Gate Block เช่นกัน

การตรวจว่า Protection/Close ยังทำงานเมื่อทุนหมดเป็นอีกสถานการณ์หนึ่งที่ต้องมี Position อยู่ก่อน ไม่ได้พิสูจน์จากกรณี Basket ว่างนี้ครับ 

### 13 — `SHORT_13_AUTOLOT.set`

ขั้นตอน:

1. โหลด Preset แล้วดู Virtual Equity และ Effective Lot
2. รอ Auto เปิดเอง แล้วตรวจ Volume จริงของทั้งสองขา
3. ตรวจสูตรที่ระดับทุนต่าง ๆ เป็น Variant แยกเมื่อ Basket ว่าง
4. บันทึก Initial Capital, REFILL และ Closed Net ทุก Variant

ทุน 50 ไม่ได้หมายความว่า Equity ยังเป็น 50 หลังรันชุดก่อนหน้า และการเปิดได้ Lot เดียวไม่ได้พิสูจน์บันไดหรือเพดานทั้งหมดครับ 

### 14 — `SHORT_14_MISSING_SL.set`

ขั้นตอน:

1. โหลด Preset แล้วกด HEDGE เปิดคู่
2. เก็บ Ticket/SL/ราคาเริ่มต้นก่อน
3. ตรวจ Fixture SL หายทีละขา เฉพาะ Demo และ Position ใน Scope นี้
4. เก็บว่า EA พยายามติดตั้ง SL กลับอย่างไร ก่อนและหลัง BE Trigger

ยังไม่ลบ SL ทันทีหลังอ่านขั้นตอนนี้ครับ ต้องเตรียมภาพ/Log และวิธีจบ Position หากติดตั้งกลับไม่ได้ก่อน ส่วนเส้นทาง “Cut Loss Modify ถูกปฏิเสธแล้ว SELL BE ต้องทำงานต่อ” ยังต้องมี rejection จริง ไม่ใช้ผลติดตั้งสำเร็จปกติแทนครับ 

## 6. Preset 15–16 — ไม่กดปุ่ม Trade

ทำเฉพาะเมื่อ Basket ว่างแล้ว

| Preset | วิธีทำ | ผลที่คาดหวัง |
|---|---|---|
| 15 Invalid BE Step | โหลดไฟล์แล้วกด OK | Init ถูกปฏิเสธเพราะ BE Trailing ใช้ Step=0 |
| 16 Invalid Pullback | โหลดไฟล์แล้วกด OK | Init ถูกปฏิเสธเพราะ Trailing เปิดแต่ Pullback=0 |

ไม่มีการกด HEDGE, REFILL หรือปุ่มปิดเพื่อทดสอบสองไฟล์นี้ เก็บข้อความ Init rejection ใน Experts/Journal แล้วกลับไปโหลด Preset ที่ถูกต้องเมื่อจบครับ 

## 7. ส่งผลแต่ละ Preset แบบนี้

คุณส่งเมื่อจบแต่ละตัวได้ โดยไม่ต้องส่งทุก Order:

```text
Preset:
Source: 1a3b38f
Environment: DEMO
เวลาเริ่ม–จบ:

Inputs ที่เปลี่ยนจากไฟล์ ถ้ามี:
ปุ่มที่กด:
เหตุที่เกิดจริง:
เหตุที่ยังไม่เกิด:
Position ค้างตอนจบ:
REFILL ที่กดระหว่างรอบ:

แนบ:
Experts
ภาพ Inputs / Trade / History ตามกรณี
CSV / State เฉพาะกรณีที่ต้องใช้
```

ผมจะช่วยอ่านและระบุผลตามหลักฐาน ไม่ใช้ “ไม่มี Error” แทนผลผ่านทุกกรณี และจะไม่สั่งแก้โค้ดหลังทุก Preset ย่อย เว้นแต่เกิดเหตุร้ายแรงที่ต้องหยุดชุดก่อนครับ 

สำหรับจุดเริ่มตอนนี้ ให้ใช้ Preset 01 ตามขั้นตอนปุ่มด้านบนก่อน ส่วน 12 และ Fixture ของ 11/14 ต้องเตรียมแยกก่อนถึงรอบนั้น การใช้ Demo ทั้งหมดทำได้ แต่ไม่ใช่โหลดครบ 16 ไฟล์แล้วจะครอบคลุมทุกกรณีโดยอัตโนมัติครับ
